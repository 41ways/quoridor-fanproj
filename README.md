# 🚧 쿼리도

![종류](https://img.shields.io/badge/%EC%A2%85%EB%A5%98-%EB%B3%B4%EB%93%9C%EA%B2%8C%EC%9E%84-7a4a2a?style=flat-square) ![인원](https://img.shields.io/badge/%EC%9D%B8%EC%9B%90-1~4%EC%9D%B8-555?style=flat-square) [![플레이](https://img.shields.io/badge/%ED%94%8C%EB%A0%88%EC%9D%B4-quoridor.41ways.workers.dev-c9572e?style=flat-square)](https://quoridor.41ways.workers.dev/) [![허브](https://img.shields.io/badge/%ED%97%88%EB%B8%8C-norara-b4571f?style=flat-square)](https://41ways.github.io/norara/)

벽을 세워 상대의 길을 굽히고, 내 말을 먼저 맞은편 끝줄에 닿게 하는 온라인 쿼리도.
**1 : 1** 또는 **4인전**. 사람이 모자라면 봇으로 채우니 혼자서도 바로 할 수 있다.

## 한눈에

| | |
|---|---|
| **종류** | 추상 전략 보드게임 · 온라인 |
| **인원** | 2인 또는 4인 (봇으로 채우면 혼자도) |
| **플레이** | **https://quoridor.41ways.workers.dev/** |
| **로컬 실행** | `npm install && npm start` → http://localhost:8795 |
| **한 줄 규칙** | 차례마다 말을 한 칸 옮기거나 벽 하나를 세운다. 누구의 길도 완전히 막을 수는 없다 |
| **허브** | https://41ways.github.io/norara/ |

## 규칙

- 9×9 판. 2인은 아래·위, 4인은 네 변 가운데에서 출발하고 **맞은편 끝줄**에 먼저 닿으면 이긴다.
- 차례마다 둘 중 하나.
  - **이동** — 상하좌우로 한 칸.
  - **벽** — 칸 사이 홈에 두 칸 길이 벽을 세운다. 2인은 10개, 4인은 5개씩.
- 벽은 겹치거나 가운데에서 엇갈릴 수 없고, **어떤 말의 길도 완전히 막으면 안 된다.**
- 말끼리 마주 보면 뛰어넘는다. 뒤가 벽·판 끝·다른 말이면 옆으로 비껴간다.
- 4인전에서 기권하거나 나간 말은 판에서 빠지고(세운 벽은 남는다), 한 명만 남으면 그 사람이 이긴다.

## 화면

- **원목 판** — 월넛 테두리, 메이플 칸, 꿀색 벽. 나뭇결은 캔버스로 한 번 그려 모든 판이 나눠 쓴다. 초록 펠트는 쓰지 않는다.
- **내 말은 늘 아래** — 어느 자리에 앉든 판을 돌려서 보여 준다. 각자의 결승선은 테두리 띠와 칸 물들임으로 표시.
- **벽 미리보기** — 칸 사이 홈을 가리키면 벽이 떠오르고, 못 세우는 자리는 빨갛게 흔들리며 이유(겹침·길 막힘·벽 없음)를 말해 준다. 폰에서는 한 번 누르면 들린 채로 기다리고, 한 번 더 누르거나 "여기에 세우기"로 내려놓는다.
- **가장 짧은 길** — 오른쪽 위 점선 단추로 모두의 최단 경로를 켜고 끈다. 판이 끝나면 저절로 보인다.
- 말은 한 칸이면 톡, 뛰어넘으면 폴짝. 벽은 떨어지며 판이 살짝 울린다. 소리는 전부 WebAudio 로 합성(파일 없음).
- 라이트/다크 테마, 이모지 반응, 방 채팅, 이기면 색종이.

## 봇

`public/rules.js` 의 `botMove`. 모든 수를 "내 최단거리 vs 가장 앞선 상대의 최단거리"로 따진다.

| 난이도 | 방식 |
|---|---|
| 쉬움 | 결승선 쪽으로 걷되 흔들림이 크고, 가끔 상대 길목에 벽 하나 |
| 보통 | 이동 + 상대 최단 경로를 끊는 벽 후보를 한 수 앞까지 본다. 뒤지면 벽을 쓰고 앞서면 아낀다 |
| 어려움 | 1 : 1 에서는 상대의 가장 아픈 응수까지 두 수를 본다 |

## 구조

```
public/rules.js   판 규칙 · 봇 · 화면 회전 — 서버와 브라우저가 같은 파일을 쓴다
public/board.js   SVG 판 그리기 (타이틀 구경판 · 규칙 그림 · 실제 판 공용)
public/app.js     화면 · 조작 · 소리
game.js           방 · 차례 · 타이머 · 봇 진행 (권위 서버, 통신 방식은 모름)
worker.js         Cloudflare Workers + Durable Object 하나에 모든 방
server.js         Node 서버 (로컬 개발 · 시험)
```

- 서버가 판을 쥔다. 화면은 `{ t:'act', a:{ k:'move'|'wall', … } }` 만 보내고, 맞는 수인지는 서버가 `rules.js` 로 판정한다.
- 새로고침·앱 전환은 `resume` 으로 같은 자리에 돌아온다. 다른 탭이 이어받으면 옛 탭은 `moved`.
- 한 수 제한 시간(30초·1분·2분·없음)이 지나면 가장 짧은 길로 한 칸 대신 옮긴다. 시간 제한이 없어도 자리를 비운 채 30초가 지나면 같다.
- 지켜보는 사람이 없으면 봇도 쉰다 — 무료 한도의 "객체가 깨어 있는 시간"을 아끼려고.

## 배포

Cloudflare Workers 무료 플랜. **GitHub 에 푸시해도 서비스는 바뀌지 않는다** — 고친 뒤 꼭:

```bash
npx wrangler deploy
node test/smoke.js https://quoridor.41ways.workers.dev
```
