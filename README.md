# 쿼리도

벽을 세워 상대의 길을 굽히고, 내 말을 먼저 맞은편 끝줄에 닿게 하는 온라인 쿼리도. 1:1 또는 4인전, 사람이 모자라면 봇으로 채운다.

https://quoridor.41ways.workers.dev/

![타이틀](assets/screenshots/title.png)

## 규칙

- 9×9 판. 2인은 아래·위, 4인은 네 변 가운데에서 출발하고 맞은편 끝줄에 먼저 닿으면 이긴다.
- 차례마다 말을 한 칸 옮기거나, 칸 사이 홈에 두 칸짜리 벽을 세운다. 벽은 2인 10개, 4인 5개씩.
- 벽은 겹치거나 가운데에서 엇갈릴 수 없고, 누구의 길도 완전히 막으면 안 된다.
- 말끼리 마주 보면 뛰어넘고, 뒤가 막혀 있으면 옆으로 비껴간다.
- 4인전에서 기권한 말은 빠지고(벽은 남는다), 한 명만 남으면 그 사람이 이긴다.

## 화면

원목 판(월넛 테두리, 메이플 칸, 초록 펠트 없음)에 내 말은 항상 아래로 보이게 판을 돌린다. 벽 세울 자리를 가리키면 미리 뜨고, 못 세우는 자리는 빨갛게 흔들리며 이유를 말해 준다. 오른쪽 위 단추로 모두의 최단 경로를 켜고 끌 수 있다.

## 봇

`public/rules.js`의 `botMove`가 "내 최단거리 vs 가장 앞선 상대의 최단거리"로 수를 고른다. 쉬움은 흔들림이 크고, 보통은 상대 길목에 벽을 한 수 앞까지 보고 놓고, 어려움은 1:1에서 상대 응수까지 두 수를 본다.

## 구조

```
public/rules.js   판 규칙 · 봇 · 화면 회전 — 서버와 브라우저가 같은 파일을 쓴다
public/board.js   SVG 판 그리기
public/app.js     화면 · 조작 · 소리
game.js           방 · 차례 · 타이머 · 봇 진행 (권위 서버)
worker.js         Cloudflare Workers + Durable Object
server.js         로컬 개발용 Node 서버
```

서버가 판을 쥐고 있어서 화면 조작으로 수를 속일 수 없다. 지켜보는 사람이 없으면 봇도 쉰다.

## 개발

```bash
npm install
npm start                                  # http://localhost:8795
npm test                                   # 규칙 15개 + 방 흐름 5개
node test/smoke.js http://127.0.0.1:8795   # 떠 있는 서버에 붙어서 한 판
npx wrangler deploy                        # 배포 — 푸시만으로는 반영 안 됨
```
